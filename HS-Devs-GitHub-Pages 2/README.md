# HS Devs — GitHub Pages

1. Extract this ZIP.
2. Upload all its contents to the root of your GitHub repository. Keep index.html beside the CSS, JavaScript, other HTML pages, and assets folder. Do not upload only index.html or the ZIP itself.
3. In your repository, open Settings > Pages.
4. Under Source, select Deploy from a branch. Select main and /(root), then Save.
5. GitHub will show your website URL when publication finishes.

No installation or build is needed. All site paths are relative, so this also works under a repository subpath.

The pharmacy is a browser-local demo. Game scores and language preferences are stored on each visitor’s browser. No real payments are processed.

GitHub instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
